# 📊 Proyecto 9 · Andes Retail

Dashboard interactivo desarrollado en **Tableau Public** para analizar el desempeño comercial de Andes Retail durante 2024–2025.

## Objetivo

Analizar ingresos, utilidad y margen para identificar el comportamiento por país, categoría de producto y segmento de clientes.

## Herramientas utilizadas

- Tableau Public
- Excel
- GitHub
